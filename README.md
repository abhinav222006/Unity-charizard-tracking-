# Unity Charizard Tracking – AR Project

## About the Project
This project is an Augmented Reality (AR) application developed using Unity. It explores AR functionality by tracking a Charizard target and displaying digital content in the real-world environment.

## Features
- Augmented Reality experience using Unity.
- Charizard target tracking.
- Interactive AR content.
- Real-time rendering of virtual objects.

## Technologies Used
- Unity
- C#
- Augmented Reality (AR)
- Git and GitHub

## Requirements
- Unity version compatible with the project.
- Required AR packages and dependencies.
- A compatible device for running the AR application.

## How to Run
1. Clone or download this repository.
2. Open Unity Hub.
3. Click **Add** and select the downloaded project folder.
4. Open the project using the compatible Unity version.
5. Open the main scene from the `Assets` folder.
6. Configure the required AR settings and run the project on a supported device.

## Project Structure
- `Assets/` – Scripts, scenes, materials, and other project assets.
- `Packages/` – Unity package dependencies.
- `ProjectSettings/` – Unity project configuration.
